# noxeval 0.7: scope adherence, saying what was asked and no more

Status: **scope approved** by Marcus (2026-10-10), with the three decisions at the end. Not implemented. Builds on 0.6 (citations by id). Additive and off by default.

## Why

Grading legal drafts written by two strong models showed a pattern no current check catches: the drafts were correct and well grounded, and still **said too much**. They repeated the same argument in two sections, cited provisions the thesis did not need, and added requests the client never made (damages nobody asked for, for example). A reviewer marks that down; a check that only asks "is it correct and supported?" passes it.

The same happens outside law: a support bot that answers the question and then three others, a summary that grows with each prompt change. "Overreach" is a quality failure of its own, and it should be measured, not guessed.

The hard rule: **never punish the grounding that actually supports the answer.** A long answer with every sentence needed is fine; a short one with an invented request is not.

## Deterministic signals first

Each one is explainable and reported per case; none needs a model.

| Signal                         | How                                                                                                                                                  | Notes                                                                                                                     |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| **Repetition**                 | Sentences whose normalized words overlap an earlier sentence above a threshold (Jaccard), and repeated long word sequences                           | A sentence that carries a required citation (`mustCite`) is never counted as a repeat                                     |
| **Extra citations**            | Cited ids outside `mustCite` and the new `mayCite`                                                                                                   | Needs 0.6. `mayCite` lists the sources that are acceptable but not required, so supporting provisions are never penalized |
| **Out-of-scope content**       | Case field `outOfScope?: string[][]`: groups of terms that mark content the case must not add ("dano moral" when the client asked only for a refund) | Like `mustNotInclude`, but it lowers the scope score and never fails the case on its own (decision 2)                     |
| **Length against a reference** | Case field `referenceWords?: number` with a tolerance                                                                                                | For tasks with a known good size; off when absent                                                                         |

**Scope report:** per case, the signals that fired, the raw measures (highest sentence overlap, length against the reference) and a 0–1 **scope score** (share of signals clean). Modes `off`, `report` and `check`, like grounding in 0.5. The config key is `scopeAdherence`.

In `check` mode, the case fails only when the score is below a `minScopeScore` the team sets; no single signal fails a case by itself. Until the thresholds are measured (decision 3), `check` refuses to start without explicit `jaccard`, `lengthTolerance` and `minScopeScore` values.

## Then the judge, checked by people

What rules can't see (an argument that is relevant but unnecessary for the thesis) goes to one atomic judge question: "Does the answer add requests, arguments or topics the question did not ask for?". The judge does not decide alone:

- **Planted errors** with subtle overreach (a correct draft plus one request nobody asked for) measure whether the judge catches it.
- **Blind review** on a sample, with Cohen's kappa, says whether the judge agrees with a professional. For legal drafts, the reviewer is a lawyer.
- Critical cases (citations, required grounds) keep **verifiable answer keys**: the judge never replaces `mustCite`.

## Out of scope

- Rewriting or trimming the answer. noxeval measures; it never edits.
- Any language-specific legal parser. The signals are generic; the case file carries the domain knowledge.

## Decisions (Marcus, 2026-10-10)

1. **Name: "scope adherence".** It names what is measured; the report calls a failing signal an overreach.
2. **`outOfScope` lowers the score; it does not fail the case on its own.** We don't know yet how many false alarms term groups raise on real drafts. Once measured, a later version may let a case mark a group as failing.
3. **Measure first, then set the thresholds.** Ship with `report` as the only default: it records the raw measures without judging. The defaults for Jaccard, length tolerance and the minimum score are set from those numbers on real drafts (the first source is Havr.IA's legal drafts, with blind review by a lawyer), and written into a later version of this spec.
