# noxeval 0.7 (draft): scope adherence, saying what was asked and no more

Status: **draft**, for Marcus to decide. Builds on 0.6 (citations by id). Additive and off by default.

## Why

Grading legal drafts written by two strong models showed a pattern no current check catches: the drafts were correct and well grounded, and still **said too much**. They repeated the same argument in two sections, cited provisions the thesis did not need, and added requests the client never made (damages nobody asked for, for example). A reviewer marks that down; a check that only asks "is it correct and supported?" passes it.

The same happens outside law: a support bot that answers the question and then three others, a summary that grows with each prompt change. "Overreach" is a quality failure of its own, and it should be measured, not guessed.

The hard rule: **never punish the grounding that actually supports the answer.** A long answer with every sentence needed is fine; a short one with an invented request is not.

## Deterministic signals first

Each one is explainable and reported per case; none needs a model.

| Signal                         | How                                                                                                                                                  | Notes                                                                                                                     |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| **Repetition**                 | Sentences whose normalized words overlap an earlier sentence above a threshold (Jaccard, default 0.8), and repeated long word sequences              | A sentence that carries a required citation (`mustCite`) is never counted as a repeat                                     |
| **Extra citations**            | Cited ids outside `mustCite` and the new `mayCite`                                                                                                   | Needs 0.6. `mayCite` lists the sources that are acceptable but not required, so supporting provisions are never penalized |
| **Out-of-scope content**       | Case field `outOfScope?: string[][]`: groups of terms that mark content the case must not add ("dano moral" when the client asked only for a refund) | Like `mustNotInclude`, but reported as overreach (usefulness), not as a forbidden term                                    |
| **Length against a reference** | Case field `referenceWords?: number` with a tolerance (default +50%)                                                                                 | For tasks with a known good size; off when absent                                                                         |

**Scope report:** per case, the signals that fired and a 0–1 **scope score** (share of signals clean). Modes `off`, `report` and `check`, like grounding in 0.5: start with `report`.

## Then the judge, checked by people

What rules can't see (an argument that is relevant but unnecessary for the thesis) goes to one atomic judge question: "Does the answer add requests, arguments or topics the question did not ask for?". The judge does not decide alone:

- **Planted errors** with subtle overreach (a correct draft plus one request nobody asked for) measure whether the judge catches it.
- **Blind review** on a sample, with Cohen's kappa, says whether the judge agrees with a professional. For legal drafts, the reviewer is a lawyer.
- Critical cases (citations, required grounds) keep **verifiable answer keys**: the judge never replaces `mustCite`.

## Out of scope

- Rewriting or trimming the answer. noxeval measures; it never edits.
- Any language-specific legal parser. The signals are generic; the case file carries the domain knowledge.
